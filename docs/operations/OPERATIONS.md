# Events 운영 안내

## 이벤트 생성과 편집

관리자 `/admin`에서 회사 Google 계정으로 로그인한다. 회사 계정은 최초 로그인 시 자동 운영자로 등록된다.

1. 템플릿으로 생성에서 공모·투표 등 기본 구성을 선택한다.
2. 이벤트 이름과 공개 주소를 입력한다. 주소는 `events.seoularena.net/입력한주소`가 된다.
3. 페이지 편집에서 모듈을 추가·삭제·정렬하고 문구·이미지·입력 항목을 설정한다.
4. 글자 크기는 H1~H4·본문, 색상은 기본·강조의 공통 스타일에서 선택한다.
5. 모바일·PC 미리보기 후 저장한다. 문의와 개인정보 처리방침, 동의문을 작성한다.
6. 공개와 참여 시작을 확인한다. 초안과 보관 이벤트는 공개하지 않는다.

본문은 영문·숫자도 Pretendard를 유지한다. 브랜드와 이벤트 헤더는 Archivo Bold를 사용한다. 모듈 설정은 허용된 항목만 저장하며 임의 스크립트나 CSS를 입력하지 않는다.

초기 단계 종류는 공모·투표·결과이며 각각 한 번씩 구성할 수 있다. 필요한 단계만 선택한다. 공개 후 단계 구성 변경에는 제한이 있으며 문구 편집과 운영 단계 전환은 별도 동작이다.

추가 입력 항목은 최대 10개이며 단문·장문·숫자·선택형을 지원한다. 값은 서버에서 검사한 뒤 개인정보와 함께 암호화 저장한다. 이미지는 JPG·PNG·WebP 업로드 후 WebP로 압축하며 저장 파일당 192KiB, 이벤트당 40개로 제한한다.

## 공모·투표·결과

응모작은 검토 대기에서 승인·반려·후보로 처리한다. 후보를 확정한 후 투표 단계로 전환한다. 전환 확인창에서 실제 공개할 후보 또는 결과를 확인한다. 서버도 현재 단계와 접수 기간을 검사한다.

투표에서는 연락처·이메일·인스타그램을 수집한다. 중복 투표 금지 설정에서는 정규화한 항목 중 하나라도 이전 투표와 같으면 차단한다. 본인인증이 없으므로 실제 동일 인물 여부를 완전히 보장하지 않으며, 공동 연락처를 사용하는 사람도 제한될 수 있다. 중복 투표 허용 여부는 운영자가 선택한다.

후보별 득표수와 순위를 확인하고 후보 중 하나를 결과로 선택한다. 강제 점수·선정 근거·다른 담당자 승인은 요구하지 않는다.

## 개인정보와 동의

동의문을 변경하면 새 버전을 만들며 참여 당시 버전과 이력을 연결한다. 개인정보는 기본 마스킹 상태다. 원문 조회는 인증된 관리자만 가능하고 조회 기록을 남긴다. 보관 기간 이후 개인정보 파기는 공모 문구·득표 집계와 구분한다. 백업 복구 시에는 이미 파기한 데이터가 복원되지 않도록 별도 확인이 필요하다.

## 테스트 데이터 초기화 후 공모 시작

대상 이벤트의 삭제 범위를 확인한 뒤 마지막 확인을 한 번 더 거친다. 응모작·개인정보·동의 이력·후보·투표·결과·중복 대조 정보가 초기화된다. 화면 문구·동의문 원문·관리자·운영 기록은 보존한다. 다른 이벤트는 변경하지 않는다.

실제 운영 데이터를 테스트 목적으로 삭제하지 않는다. 이벤트 복제는 구성과 동의문·이미지를 복사하며 참여 데이터를 복사하지 않는다.

## 현재 운영 전 확인할 제한

현재 운영 목록은 응모작·개인정보·운영 기록을 최대 200개 단위로 조회한다. 대규모 운영 전 전체 조회와 페이지 이동 기능을 추가 검증해야 한다. DNS·Google 로그인·서비스 키·Turnstile 연결 및 최종 공개 검증은 배포 안내에 따라 진행한다.

# 운영 화면·응답 개선 (2026-09-16)

## 변경
- 시작 시 전체 이벤트 동의문 조회 제거. 콘텐츠 편집 진입 시 선택 이벤트만 조회.
- 심사 상태는 행별 즉시 표시, 저장 중 다른 행 편집 가능. 실패 시 해당 행 복구. 요청 2건으로 심사 2건 처리하며 전체 상태 재조회 없음.
- RPC 인증은 매 요청 확인하되 같은 요청 내 중복 확인을 제거. 등록된 운영자는 불필요한 등록 쓰기를 수행하지 않음.
- 공개 준비 컴포넌트·스타일·중복 동의문 편집 절차 제거. 콘텐츠 편집 ‘저장 후 공개’에서 모든 구성된 단계의 동의문을 기존 불변 버전 구조로 반영.
- 현재 단계·빨간 중지 버튼, 다음 단계·상시 완료/미완료 조건. 기존 서버 전환 검증과 최신 상태 충돌 검증 유지.
- 후보 확정 전 순서 변경. 전체 ID 집합 및 활동 버전 검사, 원자적 저장. 공개 투표 순서 반영, 확정 후 변경 금지.
- 개인정보 표: 마스킹 정보·공모/투표 문구·접수일시·상태, 50건 페이지 이동, 원문 조회·삭제 확인 유지.
- 단계 구성 및 푸터 설정은 펼쳐진 컨테이너, 단계 01/02/03 표시. 이메일 입력은 mailto 링크로 저장.

## 검증
110개 단위 테스트, 타입 검사, 빌드 통과. 별도 로컬 이벤트의 251건 심사 검색·필터·페이지 이동, 전체 캠페인·초기화, 결과 선정 검증 통과. 브라우저 요청 계수(심사 2건=POST 2건), 동시 행 수정, 실패 복구, 후보 순서·확정 후 변경 거부·공개 순서, 동의문 일괄 공개 및 단계 변경 후 버전 수 보존, 마스킹 표 확인. PC·모바일 공개/단계 화면 검토 완료.

실제 운영 개인정보·이벤트 단계·문구·후보 순서는 테스트에서 변경하지 않음. 실제 네트워크 응답 시간은 사용자 환경에 따라 달라지며 로컬 검증의 요청 수 감소를 근거로 한다.

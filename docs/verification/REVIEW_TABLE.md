# 심사 표·후보 목록·메뉴 스크롤

## 변경
- PC 왼쪽 메뉴의 독립 세로 스크롤, 하단 계정 영역 유지.
- 심사: 문구·접수일시(한국 시간)·상태·상태 변경 표, 전체/검토 대기/승인/반려/후보 필터, 문구 검색.
- 서버 검색 및 50건 페이지 이동. 심사 API는 개인정보 컬럼을 조회하거나 반환하지 않는다.
- 후보·투표: 심사에서 지정된 숏리스트의 문구·득표수·확정 여부 표와 후보 확정 버튼. 직접 추가 API 및 데이터 메서드 제거.
- 후보 해제는 확정 전 숏리스트에서 제거. 확정 후보는 심사에서 변경 불가 표시, 서버에서도 기존 제한 유지.

## 검증
격리된 로컬 D1의 가상 응모 251건으로 6페이지 조회, 검색, 상태 필터, 개인정보 없는 응답, 이벤트 간 분리, 직접 추가 API 차단, 후보 지정·해제·확정 검증. 브라우저에서 메뉴 스크롤 및 PC/모바일 표 확인. 결과 선정 테스트와 공모→투표→결과→이벤트별 초기화 통합 테스트 통과. 실제 운영 데이터 변경 없음.

# 일정 모듈 시각 검토

상태: 디자인 승인 완료 (2026-09-15). 운영 배포 진행.

## 구현
- 모듈 추가 → 일정. 일정명·시작일·종료일·안내 문구 편집, 추가·삭제·위아래 이동(최대 12개).
- 기간·하루 일정·날짜 미정 지원. 공개 페이지 및 편집 미리보기 공통 컴포넌트.
- 기존 흑백 테마 토큰, Pretendard 본문. PC 카드 병렬, 좁은 화면 세로 배치.
- 안내 일정은 접수·투표 서버 개폐 일정과 별도. 에디터에서 차이를 안내한다. 실제 접수 일정 변경 없음.

## 출처·선택
[Radix 공식 컴포넌트 목록](https://www.radix-ui.com/primitives/docs/components)을 확인했다. 일정 표시 전용 컴포넌트가 없어 외부 라이브러리 추가 없이 기존 Radix 기반 라이브러리에 의미론적 목록·time 요소로 자체 작성했다. 외부 코드를 복사하지 않았다.

## 검증
- 타입 검사·빌드 통과.
- 실제 로컬 API로 모듈 추가·날짜 편집·저장·다시 읽기 확인.
- 유효 날짜·역전 기간·종료일 단독·미정 날짜 테스트 통과.
- 모바일 390px 미리보기와 PC 720px 콘텐츠 폭 이미지 확인.

- events.started_at / ended_at: UTC epoch milliseconds, 표시 시 한국시간으로 변환. 근거가 없거나 아직 발생하지 않은 날짜는 NULL.
- 기존 감사 기록을 시간순 재생. 접수 활성화·공개·예약 일정 모두 충족한 첫 시각 저장.
- 시작 전 취소/일정 변경 반영, 시작 후 재개나 편집으로 최초 시작·최종 단계 최초 진입 시각 변경하지 않음.
- 마지막 단계는 event_stages.position 순서. 단일 단계 이벤트는 실제 접수 종료 시각으로 종료 처리.
- 명시적인 테스트 데이터 초기화는 기간도 초기화.
- 관리자 조회/변경 후 재계산, 기존 15분 정기 작업으로 방문이 없는 예약 개시 및 기존 데이터 복원. 실제 시각을 저장하되 DB 반영은 최대 정기 작업 간격만큼 지연 가능.
- 재계산은 revision 조건으로 동시 수정 중 과거 계산의 덮어쓰기를 방지. 같은 값이면 DB 쓰기 생략.
- 공개 참여 API에 추가 조회를 넣지 않음. 개인정보 접근 없음.
- 사용자 운영 적용 승인 및 FIRST SEAT만 공식 발표일 2026-10-08로 수동 보정 요청. ended_at_override 별도 저장으로 자동 계산 알고리즘 유지. 날짜만 지정되어 KST 00:00 저장. 실제 2026-10-12 전환 감사 기록은 변경하지 않음.

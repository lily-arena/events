사용자 확정: 전체 투표자가 추첨 대상(인스타그램 미입력자 포함), 확인된 팔로워 우대.
제안: 운영자 수동 팔로우 상태(미확인/확인/미팔로우 확인), 배수1~100(소수1자리), 서버 가중 무복원 추첨. 매 실행은 독립, 과거 당첨 제외 없음. Meta 연동은 미구현이며 ID만으로 자동 확인되는 것으로 표현하지 않음.
미확정: 수동 검증 방법 승인, 같은 사람/인스타 ID의 복수 참여 중복 처리. 기존 코드는 참여 레코드 기준 무복원.

- 사용자 확정: 자료 업로드 후 대조 방식 유지. 시안 주석 5개 반영: 섹션 제목 수정, 기준일 설명 일부 삭제, 샘플 버튼 삭제, 추첨 소개 문장 삭제, 다운로드 가이드 번호 목록 전환.

- 실제 사용자 제공 ZIP 구조 검증: connections/followers_and_following/followers_1.json 배열, string_list_data의 value/href/timestamp. 다른 following/request/unfollow 파일은 제외. 원본 개인정보 파일은 저장소에 복사하지 않음.
- 날짜 수동 입력 제거. instagram-계정-YYYY-MM-DD-식별자.zip의 날짜를 파일명 기준으로 명시해 표시. ZIP 항목 수정 시각은 시간대 불명이라 생성시각으로 사용하지 않음. 날짜 추출 불가/여러 날짜이면 업로드 시각만 표시. 실제 개인 ZIP으로 브라우저 로컬 파싱 확인. 서버 저장 미구현.

- 사용자 승인: 시안대로 실제 적용 및 로컬 커밋. 배포/push 승인 없음.
- 구현: 기존 scoped identity HMAC을 재사용해 개인 정보 복호화 없이 대조. admin에 기존 public HMAC 키 공유 필요. 업로드 원자 교체 및 자료 ID 기반 오래된 추첨 차단.
